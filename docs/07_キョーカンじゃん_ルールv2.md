# キョーカンじゃん ゲームルール v2（正方形カード・共感一致版）

> 同じ感覚の "ご近所さん" を集めて、感じた言葉を **カードの向き** で宣言するカードゲーム

改訂の経緯・シミュレーション根拠: [[10.Projects/キョーカンラボ＆じゃん/06_キョーカンじゃん_改訂案v2_共感一致|06_改訂案v2]]
旧ルール: [[10.Projects/キョーカンラボ＆じゃん/01_キョーカンじゃん_ルール|01_ルール（v1）]]

## v1からの主な変更

1. **カードは正方形**。3辺に言葉、1辺にクラスター紋章。どの言葉を上にして置くかが「宣言」
2. **真の共感は他プレイヤーとの一致**で決まる（自分の手の中では完結しない）
3. **セットはクラスター役（同じカード×3）のみ**。v1の同色役は廃止
4. **得点は「合うたび、きゅうり1本」に統一**——役1・被り1・ピタ1
5. **手札は標準8枚**（クイック10枚。旧上級13枚は廃止）

---

## ゲームの目的

同じものを体験したときに生まれる「同じ！」「ちょっと違うかも」という感じ方を、**感覚のクラスター（言葉のご近所さん）** と **言葉の向き** でそろえて楽しむ。

正解・不正解はない。共感は競うものではなく、集まるもの。

## 使うもの

### 感覚カード：136枚（正方形）

**基本クラスターカード：132枚**

- 11クラスター × 12枚（赤3・青3・黄3・緑2クラスター。語彙は [[10.Projects/キョーカンラボ＆じゃん/02_キョーカンじゃん_カードリスト|02_カードリスト]] と同じ）
- カードは正方形で、**3つの辺にそれぞれ言葉**、**残る1辺にクラスター紋章（漢字1文字）と色**が印刷されている
- 言葉は外向き印刷——上にした言葉が、向かいの人から正位置で読める
- **どの言葉を上にして置くか＝あなたの宣言**。紋章を上にして置いたら「まだ秘密」の印

**特殊ジョーカーカード（キョーカン）：4枚**

- 言葉を持たないオールマイティカード。すべてのカードの代わりになる

その他：キョーカンバー（きゅうり）チップ

## プレイ人数・準備

- プレイ人数：3〜5人
- 全員で同じものを体験する（味わう／香りを嗅ぐ／テーマを確認する）。**1ラウンド＝1サンプル**

### 準備手順

1. カードをよく混ぜ（正方形なので卓上でかき混ぜる。ちょっと麻雀っぽい）、山札を作る
2. 各プレイヤーにカードを配る
    - **標準：8枚**（じっくり。1人3〜5周の読み合い）
    - **クイック：10枚**（テンポ約2倍。初プレイ・お子さま向け）
    - ※ 枚数が**少ないほど**長く深いゲームになる
3. 中央にキョーカンバーチップをまとめて置く
4. 最初の人が山札から1枚引いてスタート

## ゲームの流れ

### ① ターン（手札は非公開）

1. 山札から1枚引く
2. 手の中で**同じカード×3のセット（クラスター役）**を組んでいく（ジョーカー使用可）
3. いらないカードを1枚捨てる（捨て札は全員に見える場所へ）

※ この時点では言葉（向き）はまだ決めない。宣言は最後の一斉開示でまとめて行う

### ② キョーカン！（捨て札の即使用）

他の人の捨て札で**役が完成するとき**、捨てられた直後に「**キョーカン！**」と言って取れる。

- 完成したセットは表にして自分の前に置く。ただし**紋章辺を上**にして置く——どのクラスターを感じたかは公開、**どの言葉かはまだ秘密**
- その後1枚捨てて手番終了。次はその下家の番

> 公開されたセットは「あの人は赤『濃』で感じてる…」という情報になる。同じクラスターを追いかけて共感を狙う（乗っかる）か、別の表現で個性を出すか——ここが駆け引き。

### ③ アガリ

**役3組**がそろったら「**アガリ！**」と宣言する。中身はまだ見せない。

### ④ 最終ラウンド（1巡）

アガった人以外の全員が、あと1手番ずつプレイする。滑り込み完成もOK。

### ⑤ 一斉開示——向きの宣言（クライマックス）

1. 全員、自分の完成している役を（アガれなかった人も）卓に**伏せて**並べる。このとき役ごとに**感じた言葉を1つ選び、その言葉が上になる向き**にそろえる
    - ジョーカー入りのセットは、実カードの向きで宣言する
2. **せーの、で一斉オープン**
3. きゅうりを配る（下記）
4. 最後に「**一番共感したプレイヤー**」へ全員で投票

> 同じカードが違う向きで並んだら、それが「同じものを感じたのに、言葉が違った」の絵。ここから会話が始まる。

## 得点——合うたび、きゅうり1本

覚え方は「**役1・被り1・ピタ1**」。開示後、3回に分けて配る。

| 起きたこと | きゅうり |
|---|---|
| 役1組を完成させた（アガれてなくても） | **1本** |
| そのカード、他の人も役で出していた（被り） | **もう1本** |
| **向き（言葉）まで同じ**人がいた（ピタ） | **さらにもう1本** |
| 先アガリ（最初に役3組） | 1本 |
| 投票で「一番共感した」に選ばれた | 1本 |

- 配り方：「役を出した人、1本ずつ」→「カードが被った人、もう1本」→「向きまで同じ人、もう1本」の3スイープ。足し算も読み替えもいらない
- 何人と被っても本数は同じ（被り1本・ピタ1本まで）
- 減点・奪い合いはない

### 細則（テストプレイで明文化）

- 「キョーカン！」の声が複数重なったら、**捨てた人に近い下家が優先**
- キョーカン！で**3組目が完成したら、そのままアガリ**になる
- 山札が尽きたら（流局）、その時点で**一斉開示に進む**。きゅうりも通常どおり配る（先アガリの1本だけなし）

## ゲーム終了

ラウンド（＝サンプル）を替えて繰り返し、次のいずれかで終了。

- 誰かが **きゅうり10本** に到達
- 規定ラウンド消化（**2〜3ラウンド推奨**）
- 中央のきゅうりがなくなった

## 勝ち負けについて

大きな勝ち負けはつけない。きゅうりの本数は結果の記録。キョーカン王、カッパのお気に入り、など自由に呼ぶ。

## カードデザイン要件

- **正方形・回転対称レイアウト**（固有の「上」を作らない）
- 3辺に言葉（外向き・対面から読める）、1辺にクラスター紋章（濃／爽／滋／華／緑／焙／滑／鮮／印／穏／妙）＋色
- 角は丸く。リフルシャッフル不可のため「かき混ぜ洗牌」を前提にした厚めの紙がよい
- ジョーカーは全面共通デザイン（向きの概念なし）
- **裏面は90°回転対称必須**（4方向どこから見ても同一）。向きのある裏面だと、開示前の「伏せてコミット」の段階で宣言の向きが漏れる

## 超上級ルールについて

v1の超上級（頭＋4セット・14枚）は、v2のアガリ条件では**未検証・再設計中**（[[10.Projects/キョーカンラボ＆じゃん/90_開発ログ|開発ログ]]参照）。当面は標準／クイックで遊ぶ。

さらに軽く遊びたいときは、同じカードで遊べる別モード [[10.Projects/キョーカンラボ＆じゃん/08_キョーカンせーの_ルール|キョーカンせーの]] へ。きゅうりの数え方は同じ（合うたび1本）。

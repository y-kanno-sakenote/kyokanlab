# キョーカンラボ ゲームルール v2

> 感じ方をひらく、理由を探るラボゲーム

親: [[10.Projects/キョーカンラボ＆じゃん/00_index|キョーカンラボ＆じゃん]]
旧ルール: [[10.Projects/キョーカンラボ＆じゃん/03_キョーカンラボ_ルール|03_ルール（v1）]]／要因カード: [[10.Projects/キョーカンラボ＆じゃん/04_キョーカンラボ_カードリスト|04_カードリスト]]

## v1からの主な変更

1. **フレーバー提示は、じゃんの正方形カードを「向き」で出す**——専用フレーバーカード34枚を廃止。ラボの語彙34（33語＋キョーカン）は、じゃんv2の11クラスター×3語＋ジョーカーと同じ集合なので、カードを共用できる。**1つの箱で「せーの→じゃん→ラボ」の3ゲーム**
2. **質問数を明確化**：1ターンにつき質問は2問まで（v1は人数×3ターンで最大15問になり、推理が一瞬で終わっていた）
3. **選択ルール「きゅうり対戦」**（Dixit式GM得点）を追加。デフォルトは従来どおり勝敗なし
4. **サンプル選定ガイド**を新設——このゲームの面白さの9割はサンプルの組み方で決まる

---

## 使うもの

- **サンプル**：4種類程度（選び方は下記ガイド）
- **感覚カード136枚**（じゃん共通）：GMのフレーバー提示用
- **要因カード34枚**（モノ9／コト9／トキ9／ヒト・イミ・エモ7。内容は[[10.Projects/キョーカンラボ＆じゃん/04_キョーカンラボ_カードリスト|04]]のまま）
- **サンプルカード**：サンプル番号を書いたカード×人数分（トランプの1〜4等で代用可）
- （きゅうり対戦をやるなら）キョーカンバーチップ

## プレイ人数

3〜6人（チーム戦は3vs3まで）

## 準備

1. GM（ラボマスター）を1人決める
2. 全員に同じサンプルカードセットを配る
3. 全員でサンプルを一口ずつテイスティング（メモOK・食べ直しOK）
4. GMは内心で「今回の正解サンプル」を1つ選び、そのサンプルカードを伏せて手元に置く

## ゲームの流れ（3ターン）

### ① フレーバー提示

GMは感覚カードの山から1枚選び、**伝えたい言葉が上になる向き**で場に出す。

- 3ターンで合計3枚。味・香り・口あたり・全体印象、どの切り口でもよい
- 補足のひとことはOK（答えに直結する説明はしない）
- **キョーカン（ジョーカー）を出したターンはノーヒント**。GMの情報統制として使える（きゅうり対戦では特に重要）

### ② 要因カードで質問（1ターン2問まで）

研究員は相談して要因カードを2枚まで選び、1枚につき1人が質問する。

- 同じ人が1ターンに2問出さない（順番に回す）
- 質問と回答は全員で共有

### ③ GMの回答

「**はい／いいえ／どちらでもない**」＋ひとこと補足まで。

▶ ①〜③を3ターン。その後：

### ディスカッション → 回答提出 → 結果共有

- 公開された3枚（の向き）を手がかりに、全員で話し合う
- 研究員は「GMが選んだと思うサンプルカード」を一斉に表向きで提出
- GMが正解を公開し、**なぜそのカード・その言葉を選んだか**を説明。研究員も自分の感じ方とどこが違ったかを共有する

> 勝敗より「気づき」を大切に。

## 選択ルール：きゅうり対戦（Dixit式）

物足りない卓・リピート卓向け。GMを交代しながら人数分ラウンドやって、きゅうりの合計で遊ぶ。

| 結果 | きゅうり |
|---|---|
| 正解した研究員 | 🥒1本 |
| **正解者が「全員でも0人でもない」** | **GMに🥒2本** |
| 正解者が全員 or 0人 | GMは0本 |

GMの腕の見せどころは「**わかりやすすぎず、わかりにくすぎず**」。全員に当てられそうなら、あえて全体印象のカードでぼかす・キョーカンでノーヒントにする——フレーバー選びが綱渡りになり、キョーカンカードの戦略価値が跳ね上がる。

## サンプル選定ガイド（重要）

このゲームの難易度と面白さは、ルールではなく**サンプルの距離**で決まる。

### 鉄則

1. **同じカテゴリから4つ**。カテゴリ違い（りんご・チョコ・チーズ・せんべい）は1問目で当たってしまい、ゲームにならない
2. **「1軸だけ大きく違う」構成が扱いやすい**。例：カカオ%だけ違うチョコ4種。初心者卓向け
3. **上級卓は「同スペック別銘柄」**。例：純米酒・精米歩合60%前後の別蔵4本。差が微細になるほどディスカッションが深くなる
4. においの強いもの・後味の重いものは、提供順を最後にする（感覚の持ち越し防止）

### 組み合わせ例

| 難易度 | 例 |
|---|---|
| やさしい | 板チョコ（ミルク／カカオ55％／70％／85％） |
| やさしい | みかん・柑橘4品種 |
| ふつう | コーヒー同一豆の焙煎度違い4段階 |
| ふつう | 豆腐4種（絹・木綿・充填・おぼろ） |
| 上級 | 純米酒・同スペック別蔵4本 |
| 上級 | 同一蔵の温度違い（雪冷え・花冷え・常温・ぬる燗） |

### GM向けのコツ

- 最初の1枚は「4つのうち2つに当てはまる」くらいの言葉が良い（絞らせすぎない）
- 自分の感じ方に正直に。当てさせにいく必要はない——ズレそのものが結果共有の材料になる

## バリエーション（v1から継続）

- **チーム戦（3vs3）**：チームで相談して回答を提出
- **GMなし（上級）**：全員がフレーバーを共有し推理し合う
- **初心者ルール**：要因カードをモノ3／コト2／トキ3／ヒト2に制限

# キョーカンじゃん ゲームルール v4（アンカー・色自由版）

## なぜv4か（v2・v3の合流）

- **v2（色自由）**は共感が濃いが、プレイ中ずっと味を考える負荷があった
- **v3（色決め打ち）**は軽いが、「他色を捨てるだけ」で捨てがつまらなかった

v4はこの2つの良いとこ取り。**最初の1枚で軸を決めて味の判断を1回で終える（v3の軽さ）**＋**色は固定せず同じクラスターを集める（v2の共感の濃さ・捨ての判断）**。

| | 味を考えるのは | 捨ての判断 | 共感の濃さ |
|---|---|---|---|
| v2 | プレイ中ずっと（重い） | あり | 濃い |
| v3 | 最初の1回（軽い） | ほぼ無い | ふつう |
| **v4** | **最初の1回（軽い）** | **あり** | **濃い** |

## いちばん大事なコツ

1. ひと口味わったら、手札から**いちばん近い1枚を選ぶ**＝これが**アンカー（軸）**
2. アンカーと同じクラスターを、まず**1組（3枚）そろえる**——これは必ず作る
3. 残り2組は、**色は自由**。どの色でも「同じクラスター3枚」をそろえればいい
4. 引いたカードは「**どこかの3枚組に使えるか**」だけ見ればよい。味の判断は最初のひと口で終わっている

> 味わうのは最初のひと口。軸を1本立てて、あとは気楽にそろえる。

## ゲームの目的

同じものを体験したときの「同じ！」「ちょっと違うかも」を、**同じクラスターを3組**そろえ、最後に言葉の向きでそろえて楽しむ。正解・不正解はない。共感は競うものではなく、集まるもの。

## 使うもの

- **感覚カード136枚**（正方形。**中央に記号**＋3辺に言葉＋1辺に色帯。11種×12枚＋ジョーカー「キョーカン」4枚）

カードは **色（切り口）× 記号（方向）**。色は あか＝味／あお＝香り／き＝口あたり／みどり＝全体印象。記号は透視カードの ○**まる**（ゆたか）／〰**なみ**（すずやか）／☆**ほし**（際立つ）、みどりだけ ＋**十字**／□**しかく**。
**「同じクラスター」＝「同じ色の同じ記号」＝まったく同じカード**のこと（呼び方は「あかのまる」など）。詳細は [[10.Projects/キョーカンラボ＆じゃん/02_キョーカンじゃん_カードリスト|02_カードリスト]]。
- **キョーカンバー（きゅうり）チップ**

## プレイ人数・準備

- 3〜5人。全員で同じサンプルを味わう。**1ラウンド＝1サンプル**

### 準備手順

1. カードをよく混ぜて山札を作る
2. **全員で同じサンプルを味わう**
3. 手札を配る（**標準10枚**／じっくり8枚）
4. **各自、手札から「味わった感覚にいちばん近い1枚」を選ぶ＝アンカー**
    - 目印に、その1枚を自分の前に**伏せて**置く（何かは開示まで秘密。開示で一緒にめくる）
    - アンカーは手札の一部。あとでそのクラスターの役（3枚）に組み込む
5. 中央にきゅうりチップを置く
6. 最初の人が山札から1枚引いてスタート

## ゲームの流れ

### ① ターン（手札は非公開）

1. 山札から1枚引く
2. **同じクラスター3枚のセット（役）**を組んでいく（**色は自由**・ジョーカー使用可）
    - ただし1組は**アンカーと同じクラスター**で作る
3. いらないカードを1枚捨てる（捨て札は全員に見える場所へ）

※ 引いたカードは「どこかの3枚組に使えるか」で判断。どの組にもならない端を捨てる＝**何を残し何を切るかの読み合い**
※ 言葉（向き）はまだ決めない。宣言は最後の一斉開示でまとめて

### ② キョーカン！（捨て札の即使用）

他の人の捨て札で**役が完成するとき**、捨てられた直後に「**キョーカン！**」と取れる。

- 完成した役は**色帯を上**にして自分の前に公開（中央の記号は見えるので何のカードかは分かる／言葉はまだ秘密）
- その後1枚捨てて手番終了。次はその下家の番

> 誰かの捨て札で自分の狙いのクラスターがそろう瞬間の駆け引き。乗るか、別のクラスターで個性を出すか。

### ③ アガリ

**役3組**（うち1組はアンカーを含む）がそろったら「**アガリ！**」。中身はまだ見せない。

### ④ 最終ラウンド（1巡）

アガった人以外が、あと1手番ずつ。滑り込みOK。

### ⑤ 一斉開示——向きの宣言（クライマックス）

1. 全員、完成した役を（アガれなかった人も）卓に**伏せて**並べ、役ごとに**感じた言葉を1つ選び、その言葉が上になる向き**にそろえる。アンカーの1枚も一緒に
2. **せーの、で一斉オープン**
3. きゅうりを配る（下記）
4. 「**一番共感したプレイヤー**」へ全員で投票

> 同じクラスターが違う向きで並んだら、それが「同じものを感じたのに、言葉が違った」の絵。3組すべてで、この共感とズレが起きる。

## 得点——合うたび、きゅうり1本

覚え方は「**役1・被り1・ピタ1**」（せーの・v3と同じ数え方）。

| 起きたこと | きゅうり |
|---|---|
| 役1組を完成させた（アガれてなくても） | **1本** |
| そのクラスター、他の人も役で出していた（被り） | **もう1本** |
| **向き（言葉）まで同じ**人がいた（ピタ） | **さらにもう1本** |
| 先アガリ（最初に役3組） | 1本 |
| 投票で「一番共感した」に選ばれた | 1本 |

「役を出した人→クラスター被り→向きピタ」の3スイープで配る。何人と被っても本数は同じ。減点・奪い合いなし。

### 細則

- 「キョーカン！」が重なったら**捨てた人に近い下家が優先**
- キョーカン！で**3組目が完成したら、そのままアガリ**（ただしアンカーの1組が未完なら不可）
- 山札が尽きたら（流局）、その時点で**一斉開示へ**。きゅうりは通常どおり（先アガリの1本だけなし）

## ゲーム終了

ラウンド（＝サンプル）を替えて繰り返し、次のいずれかで終了。

- 誰かが**きゅうり10本**に到達
- 規定ラウンド消化（**2〜3ラウンド推奨**）
- 中央のきゅうりがなくなった

## カードデザイン要件

v2/v3と同じ（正方形・回転対称・3辺に言葉＋1辺に紋章・**裏面は90°回転対称必須**）。[[10.Projects/キョーカンラボ＆じゃん/07_キョーカンじゃん_ルールv2|07]] 参照。

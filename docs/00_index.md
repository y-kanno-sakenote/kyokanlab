# キョーカンラボ＆じゃん プロジェクト

感じ方の違いと共感を楽しむ／研究する、2種類のゲームプロジェクト。

## プロジェクト概要

同じものを体験したときに生まれる「同じ！」「ちょっと違うかも」という感覚を、カードを介して言葉にし、共有・比較する体験を提供する2つのゲーム。

- **キョーカンじゃん**：**クラスター制**の麻雀風カードゲーム。共通語彙の中で偶然の一致と微妙なズレを楽しむライトゲーム
- **キョーカンラボ**：感じ方をひらく／理由を探る推理＆ディスカッションゲーム

両ゲームとも、食品の官能評価（sensory evaluation）における「記述用語（descriptors）」を媒介として、個人の知覚を言語化・共有・比較するプロセスを体験的に学習できるよう設計されている。

## 役割分担の整理（改訂版）

| ゲーム | 立ち位置 | 主な体験 |
|---|---|---|
| **キョーカンじゃん** | アペリティフ／ライト | クラスターで偶然の一致＋宣言による微差表現 |
| **キョーカンラボ** | メインディッシュ／ディープ | 感覚の本気の言語化と推理・対話 |

キョーカンじゃんはランダム性を残したまま「**カードに書かれた複数の言葉から1つ選んで宣言する**」メカニクスで微差を表現できるよう改訂。深い表現はラボに寄せる。

## キーコンセプト

- **正解・不正解はない**：共感は競うものではなく、集まるもの
- **共通語彙の中で個人の表現を許す**：クラスターというご近所さんの中から、自分の感覚に合う言葉を選んで宣言する
- **ISO準拠の思想**：官能評価における用語の定義・選択・共有のプロセスを体験化
- **フレーバーホイール構造**：クラスターはホイール中分類に相当し、学術的にも筋がいい

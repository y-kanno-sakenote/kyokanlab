# キョーカンじゃん 感覚カードリスト（クラスター版／改訂案）

感覚カードには、**基本クラスターカード（3色 × 各3クラスター）** と **特殊色カード（緑）** がある。

色は、正しさや強さを示すものではなく、**感じ方の切り口の違い** を表す。

クラスターは、**意味的に近い言葉の "ご近所さん"** をまとめたもの。
官能評価における **フレーバーホイール（flavor wheel）** の中分類に相当する。

## カード構成全体

| 基本色クラスターカード | 3色 × 3クラスター × 12枚 | 108枚 |
| 特殊色クラスターカード（緑） | 1色 × 2クラスター × 12枚 | 24枚 |
| 特殊ジョーカーカード | 1種類 × 4枚 | 4枚 |
| **合計** | | **136枚** |

## 🟢 緑：全体印象・特殊カード（2クラスター × 各12枚 ＋ ジョーカー4枚 = 28枚）

体験全体をまとめたときの印象・評価・感じ方の軸、およびゲームを円滑にする特殊カードを表す。
緑カードも他の基本色と同様に、1枚に3つの言葉を含む「クラスターカード」として扱うが、緑のみ「2クラスター」構成となる。

### 🃏 ジョーカー「キョーカン」カード（4枚）

言葉を持たないオールマイティカード。
- **すべての色・すべての言葉の代わり** としてセットに組み込むことができる。
- ゲームの展開をダイナミックにし、役作りの自由度を高めるための特殊カード。

## 改訂前との対応

改訂前の34言葉はすべて維持されている。

- 基本色の27言葉（9×3色）→ 3語ずつクラスターにまとめ、1枚のカードに3語載せる
- 緑の言葉 → 旧版の7語から「大人っぽい」を外し、6語へ再編して2クラスター（各12枚）にまとめる。これにより『キョーカンラボ』の語彙との一貫性を保つ。さらに4枚のジョーカーを追加。

つまり、**語彙は失っていない（大人っぽい以外）**。カードへの "詰め方" を変えただけ。

## 補足

> カードの言葉や色に、正解・強さ・上下はない。
> クラスターは "感覚のご近所さん" を示しているだけで、
> プレイヤーは引いたカードのどの言葉として使うか、自分で選んでよい。

### クラスター名（漢字一文字ラベル）について

各クラスターには「濃／爽／滋／華／緑／焙／滑／鮮／印／穏／妙」という漢字一文字のラベルが付いている。
これはゲーム中の会話を軽くするため（「赤の "濃" 3枚！」のように呼べる）。
正式名称ではなく、覚えやすさのための愛称。

### キョーカンラボとの語彙共有

キョーカンラボのフレーバーカード（34枚、各1枚ずつ）は、**改訂前の単語仕様のまま**。両ゲームで同じ34語を使うので、語彙学習の連続性は保たれる。

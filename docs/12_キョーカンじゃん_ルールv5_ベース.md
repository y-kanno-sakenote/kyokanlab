# キョーカンじゃん ゲームルール v5（ベース版）

> ひと口目で「これだ」という1枚を伏せる。その1枚が、あなたの色と記号を決める。

親: [[10.Projects/キョーカンラボ＆じゃん/00_index|キョーカンラボ＆じゃん]] ／ カード: [[10.Projects/キョーカンラボ＆じゃん/02_キョーカンじゃん_カードリスト|02_カードリスト]]
検証: `dev/kyokanlab/sim/sim_cross.py`・`sim_cross_green.py`（3〜5人 各1,000ゲーム：手番13〜15・流局0%・0本で終わる人1%未満・ベース一致46〜67%）

## v4からの変更

1. **ベースカード**（v4の「軸」）を**1枚だけ伏せて脇に置く**。手札からは抜ける
2. ベースが**色と記号の十字**を引き、**その中だけで役を作る**
3. **緑は麻雀の字牌**——ベースには選べないが、**同じ緑3枚はどんな手でも1組にできる**
4. 得点は**ベース同士の照合**が主役。「あなたも同じだったの？」が毎ラウンド起きる
5. 役に言葉の宣言はいらない。**宣言はベースの1枚だけ**（＝[[10.Projects/キョーカンラボ＆じゃん/08_キョーカンせーの_ルール|せーの]]と同じ動作）

---

## ゲームの流れ（5行で）

```
手札は9枚
その中から1枚をベースに選び、最初に伏せて自分の前に置く（自分にだけ見える）
残りの8枚でスタート
1枚ツモって1枚捨てる
9枚で3セットつくれたらアガリ
```

## 使うもの

- **感覚カード136枚**（正方形。中央に記号・3辺に言葉・1辺に色帯。11種×12枚＋ジョーカー4枚）
- **きゅうりチップ**

カードは **色（切り口）× 記号（方向）**。

| | ○ まる（ゆたか） | 〰 なみ（すずやか） | ☆ ほし（際立つ） |
|---|---|---|---|
| 🔴 あか（味） | 甘い・コク・濃厚 | 酸っぱい・さっぱり・フルーティ | 苦い・うま味・香ばしい |
| 🔵 あお（香り） | 花の香り・果実様・甘い香り | ハーブ・グリーンな香り・木の香り | スパイシー・コーヒー・香り高い |
| 🟡 き（口あたり） | なめらか・まろやか・クリーミー | しっとり・すっきり・みずみずしい | とろける・ぷちぷち・シャープ |

🟢 **みどり**（全体印象）は専用の2種：**＋十字**（バランス・きれい・やさしい）／**□しかく**（余韻・奥深い・不思議）

## プレイ人数・準備

- 3〜5人。全員で同じものを味わう。**1ラウンド＝1サンプル**

1. カードをよく混ぜ、**各自9枚**配る
2. **全員で同じサンプルを味わう**
3. **各自、手札から「いちばん近い1枚」をベースに選ぶ**
    - **感じた言葉を上にした向きで、伏せて自分の前に置く**（他の人には見せない）
    - ベースは最後まで動かせない。捨てることも変えることもできない
    - **みどりとジョーカーはベースにできない**
4. 残った**8枚が手札**。中央にきゅうりチップを置く
5. 最初の人がツモってスタート

> ベースを選ぶ＝「私はこのサンプルをこう感じた」の表明。ここだけが感覚の仕事で、あとは麻雀。

## つくれる役（3枚1組）

ベースが引く**十字**——ベースの色の線と、ベースの記号の線——の中だけで組む。

| 役 | 中身 | 例（ベースが「あかの○」なら） |
|---|---|---|
| **色そろい** | ベースと同じ色 3枚（記号は自由） | あか○・あか〰・あか☆ |
| **記号そろい** | ベースと同じ記号 3枚（色は自由） | あか○・あお○・き○ |
| **まんなか** | ベースと同じカード 3枚（色も記号も一致） | あか○・あか○・あか○ |
| **みどり** | 同じみどりカード 3枚 | ＋・＋・＋ |

- **みどりはベースの十字の外だが、誰でもいつでも作れる**（麻雀の役牌と同じ）。全体印象は、どの切り口で感じていても湧くから
- ジョーカー「キョーカン」はどの役の代わりにもなる
- ベースの札そのものは役に使わない（脇に置いたまま）

## ゲームの流れ

### ① ターン

1. 山札から1枚ツモる（手札9枚になる）
2. **9枚で3セットできていればアガリ**
3. できていなければ1枚捨てる（手札8枚に戻る）

※ 十字の外の札は基本すぐ捨てる。悩むのは「色線に寄せるか、記号線に寄せるか」

### ② キョーカン！

他の人の捨て札で**役が1組完成するとき**、捨てられた直後に「**キョーカン！**」と言って取れる。

- 完成した役は表にして自分の前に公開する
- その後1枚捨てて手番終了。次はその下家の番
- 声が重なったら、捨てた人に近い下家が優先。ただし**そのキョーカンでアガリになる人がいれば、順番より先にその人が取る**（麻雀のロンと同じ扱い）
- アプリ版は早押しではない。宣言をいったん集めてから上の順で決める

### ③ アガリ → 最終ラウンド

3セットそろったら「**アガリ！**」。アガった人以外が、あと1手番ずつプレイする（滑り込みOK）。

### ④ 一斉開示——せーの

1. 全員、完成した役を表にして並べる
2. **「せーの」で、全員がベースを表にする**
3. きゅうりを配る（下記）
4. 最後に「**一番共感したプレイヤー**」へ全員で投票

> ベースをめくる瞬間がこのゲームの山場。「え、あなたも"あかのまる"だったの？しかも"コク"？」

## 得点——合うたび、きゅうり1本

| 起きたこと | きゅうり |
|---|---|
| 役1組（どの役でも） | **1本** |
| **まんなか**（ベースと同じカード3枚）を作った | もう**1本** |
| そのまんなかが、**誰かのベースと同じカード**だった | さらに**1本** |
| **ベースが他の人と同じカード**だった | **2本** |
| さらに**その言葉まで同じ**だった | もう**1本** |
| 先アガリ | 1本 |
| 投票で「一番共感した」に選ばれた | 1本 |

- ベース一致は**何人と重なっても2本**（言葉一致も1本まで）
- 減点・奪い合いはない

### 目安（シミュレーション）

- 1ラウンドで1人あたり **きゅうり3.8〜4.0本**、**10本まで2.5〜2.7ラウンド**
- **ベースが誰かと一致するのは46〜67%**（人数が多いほど高い）。一致したとき、**言葉まで同じ確率は85%前後**
- まんなかが誰かのベースど真ん中に刺さるのは**4〜5%**（ジャックポット）

## ゲーム終了

- 誰かが**きゅうり10本**に到達
- または規定ラウンド消化（**2〜3ラウンド推奨**）

## 細則

- 山札が尽きたら（流局。ほぼ起きない）その時点で一斉開示へ。きゅうりは通常どおり（先アガリの1本だけなし）
- キョーカン！で3組目が完成したら、そのままアガリ
- ベースは開示まで誰にも見せない。捨て札から他の人のベースを読むのがこのゲームの駆け引き

---

## なぜこの形なのか

- **「揃っても上がらない」問題がない**：ベースは場を決めるだけで、3枚揃える義務がない
- **捨てるのがつまらない問題がない**：十字の外を切るだけでなく、「色線か記号線か」の選択が毎ターンある
- **十字が自動的に釣り合う**：役の条件は緩いが、使える札が60〜72枚に絞られるので速くなりすぎない
- **感覚の仕事は最初のひと口だけ**：以降は麻雀。味を考え続ける負荷がない
- **共感が必ず起きる**：ベース照合は3枚集める運に左右されないので、毎ラウンド誰かに「同じだった」が起きる

---

## ひとこと

> ひと口目で決めた1枚を、最後にみんなでめくる。
> そこで重なったら、それが共感です。

# 学術的背景｜官能評価用語選抜の検討（Step1〜4）

「キョーカンラボ／キョーカンじゃん」で用いる感覚用語を、恣意的にではなく **官能評価学（sensory evaluation）の体系** に基づいて選抜・整理するための学術的検討メモ。

元資料：`官能評価用語選抜かべうち/step1.txt 〜 step5.txt`

## 全体ロードマップ

1. **Step1**｜学術的に正当な「枠組み」を確定
2. **Step2**｜官能評価用語論文を「網羅的に拾う検索軸」を確定
3. **Step3**｜論文メタ情報リスト（CSV）を作る
4. **Step4**｜lexicon論文から「実際の用語」を抽出
5. **Step5**｜ゲーム用語彙（一次語彙）へ再編成（未着手）
6. **Step6**｜共感じゃん／共感ラボの学術的説明文を完成（未着手）

## Step1｜学術的枠組みの確定

### 結論（企画書・助成金にそのまま書ける形）

> 共感じゃん／共感ラボは、食品の官能評価において用いられる記述用語（sensory descriptors）を媒介として、個人の知覚を言語化・共有・比較するプロセスを体験的に学習するためのツールである。
> これは、官能評価学における「用語の定義と共有が評価の再現性と合意形成に不可欠である」という考え方に基づいている。

### 拠り所にする学術基盤

#### ① 官能評価用語は「勝手に選んではいけない」

- 官能評価では、用語は**定義され、共有され、訓練されるべき対象**
- 個人語彙のままでは評価の信頼性が下がる
- これは ISO（International Organization for Standardization）が明確に規定している

#### ② 関連ISO規格

| 規格 | 内容 | ゲームでの位置づけ |
|---|---|---|
| **ISO 5492** | Sensory analysis — Vocabulary（基本概念・用語の正式定義集） | カードの言葉の定義基盤 |
| **ISO 11035** | Identification and selection of descriptors for establishing a sensory profile | 「語彙を選ぶゲーム」の核心ロジック |
| **ISO 13299** | General guidance for establishing a sensory profile | 個人評価 → 共有 → 議論 → 合意のプロセス |

#### ③ ISO 11035 が定める用語選抜プロセス

記述用語は、

1. サンプル群から網羅的に抽出され
2. 意味の重複や曖昧さを整理され
3. 定義と参照見本によって固定され
4. 評価に適した語のみが選択される

→ **「語彙を選ぶゲーム」自体が、ISO準拠のプロセス。**

#### ④ レビュー論文が示す lexicon の役割

- **Suwonsichon (2019)** *The Importance of Sensory Lexicons for Research and Industry*
- Lexicon（官能評価語彙集）は、研究者間／開発者と評価者／専門家と非専門家の**共通言語**として機能する
- 言語化そのものが、知覚の精度と共有性を高める

> 「共感」を生むのは感覚ではなく、"共有された言葉"である ── という思想は、学術的に明確。

### 整理：ゲーム要素 ↔ 学術対応

| ゲーム要素 | 学術的対応 |
|---|---|
| 用語カード | Sensory descriptors |
| 用語の選択 | ISO 11035 |
| 定義・分類 | ISO 5492 |
| 議論・推理 | Sensory profiling |
| 合意形成 | ISO 13299 |
| **クラスター構造（じゃん改訂版）** | **Flavor wheel（中分類層）** |
| 共感 | Lexicon共有による知覚の可視化 |

→ **完全に官能評価学の上に立っている。**

### 補足：クラスター構造とフレーバーホイール

キョーカンじゃん改訂版で導入された **「クラスターカード」** 構造（同色内で3語をまとめる）は、官能評価学における **フレーバーホイール（flavor wheel）** の構造そのもの。

- フレーバーホイールは「中心カテゴリ（例：fruity）→ 細分化（citrus, berry, tropical）」という階層を持つ
- キョーカンじゃんのクラスターは「色（大分類）→ クラスター（中分類）→ 個別語（細分類）」と同型
- 例：赤②「爽」軽やか系（クラスター）= 酸っぱい・さっぱり・フルーティ ── これは典型的なホイール中分類

> プレイヤーが「同じクラスターでも、どの語として使うか」を選択する行為は、**フレーバーホイールを下方向に辿る感覚を体験的に再現**している。

## Step2｜網羅的検索の設計

### Step2のゴール

- 「恣意的に選んでいない」ことを説明できる
- どの食品ジャンルにも横展開できる
- NotebookLM／CSV化／辞書化にそのまま使える

### 「網羅的」と言える条件

1. 複数の同義語を含む検索語群
2. レビュー論文＋一次研究論文の両方を含む
3. 食品カテゴリ横断
4. 用語"そのもの"を扱っている論文に限定

### 検索軸①：用語の言い換え

#### A. 「官能評価用語」を指す主要語群

```
"sensory lexicon"
"sensory vocabulary"
"sensory descriptor"
"sensory descriptors"
"descriptive terms"
```

#### B. ホイール系（語彙整理の典型）

```
"sensory wheel"
"flavor wheel"
"aroma wheel"
```

#### C. 手法名（lexicon論文が紛れ込む）

```
"descriptive analysis"
"quantitative descriptive analysis"
QDA
"sensory profiling"
```

→ A＋B＋C を束ねないと"抜け"が出る。

### 検索軸②：食品限定フィルタ

```
food OR beverage OR dairy OR cheese OR coffee OR tea OR beer OR wine OR fermented
```

※ 清酒は後で別枠（日本語＋J-STAGE）で扱うのが合理的。

### 検索軸③：レビュー論文

```
review OR overview
```

レビュー論文を起点に、引用文献を芋づる式に拾う。

### 完成形：基幹クエリ（英語）

```
(
  "sensory lexicon"
  OR "sensory vocabulary"
  OR "sensory descriptor*"
  OR "sensory wheel"
  OR "flavor wheel"
)
AND
(
  food OR beverage OR dairy OR cheese OR coffee OR tea OR beer OR fermented
)
AND
(
  "descriptive analysis"
  OR QDA
  OR "sensory profiling"
)
```

レビュー絞り込み用：`AND (review OR overview)`

### 日本語論文用（J-STAGE等）

```
官能評価 用語
官能評価 語彙
官能評価 記述語
食感 用語 整理
```

→ 日本語論文は「食感」「風味表現」に強い（カード設計に超有用）。

### 除外基準／採用基準

**❌ 除外**

- 単なる嗜好評価（liking / preference）のみ
- 化学分析のみ（GC-MSだけ等）
- 官能評価はしているが用語リストが提示されていない
- 用語が自由記述のみで整理されていない

**✅ 採用**

- 用語リスト／表／付録がある
- descriptor selection / lexicon development が明示されている
- sensory wheel / category map を含む

## Step3｜論文メタ情報CSVの設計

### 推奨カラム

| カラム | 内容 |
|---|---|
| `genre_food` | 食品カテゴリ |
| `year` | 出版年 |
| `title` | 論文タイトル |
| `authors` | 著者 |
| `journal_or_source` | 掲載誌・出典 |
| `type` | Review / Lexicon paper / Wheel / Standard / Resource など |
| `lexicon_terms_count` | 用語数（分かる範囲で） |
| `has_definitions` | 定義の有無（Yes/No/不明） |
| `has_reference_standards` | 参照見本の有無（Yes/No/不明） |
| `doi` | DOI |
| `url` | URL |
| `notes` | ゲーム設計に効くメモ |

ファイル：`kyokan_sensory_lexicon_papers_seed.numbers`（同フォルダ内）

- World Coffee Research の Sensory Lexicon（PDF＋公式ページ）

- Brewing malt の lexicon＋sensory wheel 論文

## Step4｜用語抽出と辞書化

### Step4のゴール

- 論文ごとに散在する用語を、共通フォーマットで統合
- **一次語彙（カード候補）** として使える状態にする
- 出典（論文／標準）を必ず紐づける

### 用語辞書CSVの規格

| カラム | 内容 |
|---|---|
| `descriptor_en` | 原語 |
| `descriptor_ja` | 日本語 |
| `attribute_level` | 上位属性：aroma / taste / flavor / texture / aftertaste / appearance |
| `category` | 例：fruity / nutty / sweet など（クラスターに相当） |
| `definition` | 論文記載 or 要約 |
| `reference_standard` | 参照見本：例「vanilla solution」等 |
| `food_domain` | coffee / cheese / malt / cross-food など |
| `source_title` | 出典 |
| `source_year` | 出典年 |
| `source_type` | Lexicon paper / Wheel / Standard |
| `confidence` | High（定義＋参照あり）／ Mid ／ Low |

→ ISO 11035 の「定義＋参照で意味を固定する」思想を反映。
→ `category` カラムは、改訂版キョーカンじゃんの **クラスター** と対応する。

### 抽出ルール（恣意性の排除）

| 区分 | 条件 |
|---|---|
| **採用**（カード化OK） | lexicon / descriptor list / wheel に明示的に掲載／定義 or 使用説明がある／パネル合意で選抜された語 |
| **保留**（後で整理） | 自由記述由来だが頻出／定義が弱い（レビューで補強） |
| **除外** | 評価語ではなく感情語のみ（like, pleasant だけ等）／サンプル固有名（商品名） |

### 抽出例①：コーヒー（World Coffee Research, Chambers "Living Lexicon"）

| descriptor_en | descriptor_ja | attribute_level | category | reference_standard | confidence |
|---|---|---|---|---|---|
| Fruity | 果実様 | aroma/flavor | fruity | エステル標準液 | High |
| Citrus | 柑橘様 | aroma/flavor | fruity | クエン酸溶液 | High |
| Nutty | ナッツ様 | aroma/flavor | nutty | ピーナッツ | High |
| Bitter | 苦味 | taste | basic taste | カフェイン溶液 | High |
| Astringent | 渋味 | mouthfeel | tactile | 明礬溶液 | High |

→ High が多い＝ゲームの「基準カード」に最適。

### 抽出例②：チーズ（Rétiveau et al., 2005）

| descriptor_en | descriptor_ja | attribute_level | category | food_domain |
|---|---|---|---|---|
| Milky | 乳様 | aroma/flavor | dairy | cheese |
| Buttery | バター様 | aroma/flavor | dairy | cheese |
| Sulfurous | 硫黄様 | aroma | sulfur | cheese |
| Acidic | 酸味 | taste | basic taste | cheese |

### 抽出例③：日本語対応（Hatakeyama et al., 2023, ミルクコーヒー）

- 「コク」「まろやか」「後キレ」など
- 日本酒・発酵食品カードに転用可能
- 英語直訳では拾えない語彙が出る

### 得られる「確実な一次語彙群」

| 系統 | 用語例 |
|---|---|
| 香り系 | fruity / floral / nutty / sulfurous / roasted … |
| 味系 | sweet / sour / bitter / salty / umami |
| 口当たり | astringent / oily / creamy / viscous |
| 後味 | lingering / clean / harsh |

→ 食品横断で再利用できる「コア語彙」が見える。

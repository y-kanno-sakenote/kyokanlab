# キョーカンせーの ゲームルール（ライトモード）

> 1枚選んで、向きを決めて、せーの。5分でわかる共感ゲーム

親: [[10.Projects/キョーカンラボ＆じゃん/00_index|キョーカンラボ＆じゃん]]

[[10.Projects/キョーカンラボ＆じゃん/07_キョーカンじゃん_ルールv2|キョーカンじゃん]] と**同じカードで遊べる別モード**。セット集めを丸ごと外し、「向きで宣言→一斉公開→一致の深さで得点」だけを取り出した最小形。アイスブレイク・体験会・ワークショップの導入・じゃんのルール説明の前振りに。

## 使うもの

- 基本クラスターカード132枚（**ジョーカー4枚は抜く**）
- サンプル（全員で味わえるもの）1〜数種

## プレイ人数

3〜8人（多いほど一致イベントが増えて盛り上がる）

## 準備

1. 各プレイヤーに手札6枚を配る
2. 全員で同じサンプルを体験する

## 1ラウンドの流れ

1. 手札から1枚選び、**感じた言葉が上になる向き**で自分の前に**伏せて**出す
2. 全員そろったら「**せーの**」で一斉オープン
3. きゅうりを配る——**合うたび1本**（[[10.Projects/キョーカンラボ＆じゃん/07_キョーカンじゃん_ルールv2|じゃん]]と同じ数え方）：

| 起きたこと | きゅうり |
|---|---|
| 同じ**色**の人がいた | **1本** |
| 同じ**カード**の人もいた | **もう1本** |
| **向き（言葉）まで同じ**人がいた | **さらにもう1本** |

- 「色の人、1本→カードの人、もう1本→向きの人、もう1本」の3スイープで配る
- 深く合うほど勝手に増える（ピッタリの人は自動的に3本）。何人と合っても本数は同じ

4. 出したカードを捨て、山札から1枚補充する
5. これを**5ラウンド**繰り返して1ゲーム。きゅうりの合計を数える。サンプルを替えてもう1ゲームしてもよい

## ちょっとした科学

でたらめに出したときの一致率は、およそ **色26%・カード9%・言葉3%**。

それを超えた分が、この卓の「共感度」。同じサンプルを深掘りしていくと、ラウンドが進むほど一致率が上がっていく——語彙がそろっていく（官能評価でいう lexicon の形成）のを、その場で体感できる。

## バリエーション

- **お題替え**：ラウンドごとにサンプルの別の側面をお題にする（「香りだけで」「後味だけで」）
- **共感度メーター**：卓全体の一致数をラウンドごとに記録し、伸びを楽しむ（研修・授業向け）
